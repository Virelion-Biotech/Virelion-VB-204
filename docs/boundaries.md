# Boundaries (Locked)

These boundaries apply to every analysis, ranking, and recommendation produced by this repository.

1. **Predictions and prioritization only**  
   This work generates predictions and prioritization. It does not generate efficacy or safety claims.

2. **Literature- and public-data-derived parameters**  
   All parameters remain literature- or public-data-derived until experimental calibration data exist.

3. **No wet-lab execution parameters**  
   No gene-editing sequences, culture recipes, release criteria, cell doses, or surgical instructions are specified.

4. **Layer 2.5 gate is mandatory**  
   Risk scores and rankings produced before the Layer 2.5 benchmark gate is passed are provisional/exploratory only. They must not be used as the basis for architecture down-selection or experimental resource allocation.

5. **Public stack only**  
   The pipeline relies exclusively on public, published data and open-source/published methodology. No proprietary third-party code or unpublished data is required to start.

6. **Discovery-stage language**  
   Statements about VB-204 itself remain proposals and hypotheses unless explicitly marked otherwise. No claim of remuscularization, arrhythmia-free engraftment, or therapeutic readiness should be inferred from computational results alone.

These boundaries are part of the program’s scientific discipline and are not optional.
